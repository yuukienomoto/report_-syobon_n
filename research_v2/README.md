# 麻雀の段位別行動分析・改善版 v2

対象は「しょぼんｎ」本人の低段位期と高段位期の比較です。改善版20特徴量を旧23特徴量と別に保存します。既存Notebook・H1〜H6・旧モデル・旧CSVを変更しません。

## 実行済みと未実行

- 旧23特徴量の実装監査、改善版の実装、合成データの検証を実施しました。
- 実牌譜1件の手牌復元を照合しました。全対局の整合性を保証する結果ではありません。
- 全対局ZIP・Drive上のCSVをこのローカル環境で取得していないため、改善版の群間差・全件時系列分析・実データLightGBM・外部性能は未算出です。
- 従来AUC0.8340、外部Accuracy35.59%、H5の既報結果は比較用参考値です。今回再現した結果とは区別します。

## Colabでの手順

`reanalysis_v2.ipynb` を開き、セル番号順に実行します。初回はC1のライブラリ導入後にColabのセッションを再起動し、C1を再実行してください。コードはNotebook内の固定コミットから取得します。

1. **C1**：コード・依存関係の準備、Drive接続、単体テスト。
2. **C2**：入力パスと新しい実行フォルダを設定。再開時は表示された `RUN_DIR` を指定。
3. **C3**：旧CSVのハッシュ確認、共通対局の確認、ZIP解析予定件数と既存キャッシュを表示。
4. **C4**：しょぼんｎの少数牌譜を試験抽出。これは全件検証ではありません。
5. **C5**：しょぼんｎを改善版で全件抽出・検査。新版キャッシュは再利用します。
6. **C6**：旧版・新版の同じ窓で記述比較、分布図、月別推移、欠損・機会数を保存。
7. **C7**：同じ固定条件で旧23特徴量と改善版の時間帯3分割評価。改善版の最終モデル・補完値・方針を外部評価前に固定。
8. **C8**：ウルトラ立直の新版特徴量を抽出・検査。モデルの調整は行いません。
9. **C9**：固定モデルの外部評価。完了済みの同じ入力・モデルは保存結果を再読込。
10. **C10**：性能比較表、日本語結果・考察、実行状態を保存。

全件抽出には時間がかかります。C3/C4で件数・エラーを確認してからC5へ進みます。中断しても250件ごとの署名付きキャッシュを再利用します。モデル学習はC7、外部採点はC9だけです。

## 解析方針と制約

- 段位≤16／≥18。17は履歴に含め、採点しません。最初の1500観測対局と同じ時間帯までを採点外とし、利用可能な初期履歴は窓に残します。
- 主方式は `hour_invariant`。終端時間帯が1対局で、10対局窓の先頭が同一時間帯を途中で切らない窓だけを使います。完全な対局履歴や厳密な時間順序を確認したことにはなりません。
- `order_verified=False`、`full_history_confirmed=False`。未解決アーカイブ要素も記録します。
- 記述分析は**無補完**。特徴量ごとに10対局全部に値がある窓だけで平均を計算します。欠損・有効サンプル数を必ず確認してください。これはH4の補完済み分布と異なります。対局単位・非重複窓・機会重み付き集計を併記します。
- モデルのみ訓練区間の生特徴量平均で補完します。全欠損の特徴量を勝手に落としたり0補完せず、その学習を停止します。旧版の交差5特徴量は旧18特徴量補完後に同じ式で生成します。
- 時間帯の境界で学習・検証を分け、検証ブロックの最初の9対局は履歴専用とします。窓の元対局IDと補完推定IDの重複を検査します。
- 両者の共通対局は学習補完から除外し、それを含む学習窓も除きます。履歴の行を削除して10対局を詰め直しません。
- LightGBMは200木、深さ5、学習率0.03、balanced、乱数42等を固定。旧設定の `subsample_freq=0` を明示し、従来と同様に行サンプリングは無効です。早期終了・探索・外部による閾値調整はありません。
- 単一クラス評価のAUC・Balanced Accuracyは算出しません。対局終了後の段位分類であり、対局前の勝敗予測ではありません。
- 生涯履歴、同一時間帯順序、未確認の特殊ログ、他プレイヤー全体への一般化、因果効果は保証できません。

## ファイルの役割

| ファイル | 役割 |
|---|---|
| `legacy_feature_audit.csv` | 旧23特徴量の全項目監査（A0/B5/C12/D6） |
| `feature_definitions_v2.csv` | 改善版20特徴量の式・イベント・分母・制約 |
| `old_to_v2_mapping.csv` | 旧版と新版の意味の対応。尺度変更を明示 |
| `mahjong_research/tenhou.py` | 牌譜イベントから手牌を復元して新版を抽出 |
| `mahjong_research/inputs.py` | 旧キャッシュ検証、新版バッチキャッシュ、入力監査 |
| `mahjong_research/legacy.py` | 保存済み旧18特徴量と変更しない交差5式 |
| `mahjong_research/analysis.py` | 時間帯窓、記述統計、図、固定モデル、外部評価 |
| `mahjong_research/reporting.py` | 新旧比較、分母集計、日本語レポート |
| `tests/` | イベント・時系列・欠損・キャッシュ・固定モデルの検査 |
| `docs/` | 実装監査、論文文章案、実行済み検証と未確認事項 |

ローカル検証は `python -m unittest discover -s tests -v`。依存関係は `requirements.txt` を使い、Python 3.12で検証しています。Windowsの一時フォルダ権限が制限される場合は、書込可能な作業フォルダを一時領域に指定してください。

旧23特徴量は従来結果の再現用には保持しますが、その名前どおりの戦術概念を測った値としてそのまま解釈することは推奨しません。改善版も、全件の品質表を確認する前に研究結果として採用しないでください。
