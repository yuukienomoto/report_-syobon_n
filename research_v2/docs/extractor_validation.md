# 改善版抽出器の検証記録

## 実行済み

`mahjong_research/tenhou.py` は標準ライブラリのみで実装した別バージョンの20特徴量抽出器である。旧23特徴量の処理は変更していない。定義、分子、分母、欠損条件、利用イベント、解釈上の制約は `feature_definitions_v2.csv` に出力した。

2026年11月4日、合成牌譜・境界条件による **25件の単体テストが全件成功**した。検査対象には、チー・ポン・大明槓・暗槓・加槓の復号と手牌更新、通常形・七対子・国士無双、両面・嵌張・辺張・単騎・双碰の候補分類、所有牌の5枚目を待ち候補にしない処理、成立リーチの宣言打牌後スナップショット、未成立リーチの除外、将来の河・ドラ表示を過去の計算に使用しない処理、複数リーチ者の個別計数、通常流局と特殊流局の区別、二重ロンの後続和了者の手牌照合、欠損と0の区別、復元不整合・切断ログの停止を含む。

ローカルに存在した、研究対象本人「しょぼんｎ」の実牌譜1件 `2011011315gm-0009-0000-2508363c`（開始段位コード1、GO type 9）を読み取り専用で再生した。原牌譜はGitHubに含めていない。

|---|---:|

同一入力を2回抽出し、監査カウンタと特徴量値が欠損の位置を含めて一致した。機械可読の結果、ソースファイルSHA-256、抽出器SHA-256は `extractor_validation.json` に記録した。

## 検査で修正した境界処理

- 宣言打牌の記録がない `REACH step=2` は不正として停止する。
- 二重ロンで対象者が2番目に記録される場合も、対象者の開示手牌を照合する。
- 対象者名の重複は「別プレイヤー」として除外せず、曖昧な入力として停止する。
- ドラ表示牌の同一136牌IDの重複、表示牌6枚以上は停止する。

## 未検証・解釈上の限界

この実牌譜1件では、自分の暗槓・大明槓・追っかけリーチの実例は確認できていない。合成データの成功を、対象ZIP全件の復元確認に置き換えない。全件再抽出時の不整合件数を別途確認し、不整合対局を削除して10対局窓を詰め直してはならない。

形状テンパイは和了形を完成する牌種があることを意味し、役、フリテン、山の残枚数を判定しない。待ちの分解が複数ある場合は複数の解釈を許す。「両面解釈可能率」を一意な良形率とは呼ばない。現物は対象リーチ者自身の判断時点までの河に限定し、他家がリーチ後に通した牌まで含めた全安全牌集合ではない。表ドラは表示牌の重複を反映するが赤・裏ドラを含めない。

`order_verified=False` と `full_history_confirmed=False` は維持する。ここでは全データの低・高段位比較、モデル再学習、外部評価は実行していない。単体テストと1対局の整合性検査から、特徴量の群間差や性能改善は主張できない。
