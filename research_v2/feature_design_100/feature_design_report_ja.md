# 打牌判断100候補の設計

設計日：2026-11-20（日本時間）。参照した作業ブランチの先頭は `9569c9e0458526dc8e3d58825eb839cdc3a2b672`。設計のみであり、新抽出・全対局解析・学習・候補の実測品質評価は行っていない。

## 目的と候補集の読み方

低段位期・高段位期で「どの選択肢があった時に、何を選んだか」を測る。対象は主として同一人物の段位期比較であり、一般的な強者・弱者の差や成長の原因とは同一でない。群内の安定性と群間の差は別々に測定する。高段位側が高いという方向仮説は固定しない。

100候補は押し引き20、牌効率・手牌構成25、リーチ15、副露15、守備15、点況10。実装可能性はA（現行状態・判定の組合せ）8、B（追加判定が必要）92。Aも抽出済み・実測安定を意味しない。C（現データでは正確に測れない）の設計は本100行に入れず、意図ログ・真の危険度・期待順位等を別途保留した。

100は検討用の**条件付き仮説の数**であり、100個の独立した着想・独立検定・完全新規情報という意味ではない。同じ基本判断の意味のある進行段階分割、既存30候補の再定義、既存23＋新4との部分重複を含む。元の23特徴量の単純複製は避け、`overlap`列で系列を公開する。候補を一括してモデル投入する計画ではない。

CSVは各行を A判断場面 → B選択肢 → C分母 → D分子 → E限界 の順で読む。追加条件、理由、必要XML情報、実装根拠、機会希少性、優先度も併記した。原則は基本判断に1条件を足す。選択肢を合法に定義するための共通条件は、恣意的な条件細分化に数えない。一部の競合・履歴候補は2条件以上になり、その希少性を高と記載した。

## 共通の厳密な測定規約

### 時点・対象・選択肢

- 判断直前の本人の純手牌をH、固定副露をM、合法な打牌候補（136牌ID）をD、実行打牌をaとする。赤牌を含む物理牌は保持し、同じ牌種の形状判定だけ共有する。現行仕様と同じく対局単位のカウンタを保存する。
- Fは本人の通常ツモに続く実自由打牌。自己成立リーチ後、鳴き直後、前回自己打牌（局頭はINIT）から誰のカンも挟んだ局面を除く。自己の今回のREACH step1宣言打牌は含む。F0は他家成立リーチ0人、F1は1人、Fmは2人以上。成立はstep2。ツモ和了・槓を選んだ全行動の比率ではなく、実打牌に条件付けた指標である。
- 条件は実際に選んだ打牌の結果で対象者を選ぶのではなく、判断前の全合法候補から計算する。未来のイベントは、直後の応答を観測する場合を除き使わない。応答の対応付けに後続Nを読むことと、将来のツモ牌を説明変数にすることを区別する。
- 各行に記載した集合X・Yは両方非空であることを要求する。X/Yは排他的に定義する。最小・最大の同値候補は全て含む。実行がXなら分子1、Yなら0、どちらでもなければ分子0かつ`other`を保存。**otherを消してX対Yの二択率へ変えない。** XとYの出現条件を満たしても、実行が全合法集合外なら抽出失敗。
- 1機会のキーはgame_id、INIT通算番号、XMLイベント番号、対象者、feature_id。複数リーチ人数や複数の同値牌候補を掛けて計数しない。局内反復は独立な試行と断定しない。
- 完全な本人手牌復元、元XML/C5ハッシュ一致を前提とする。未対応ルール・必要値不明・判定器の不整合はunknown/errorとして別記。真の分母0と混ぜない。未知機会を落とした部分比率を完成した指標として使わず、対象対局/窓のstatusを保留する。

### 進行・待ち・可視情報

- 候補dを除いた手牌の形状待ちをW(d)=既存wait_shapesとする。T={d:W(d)非空}。ryanmenは少なくとも1待ち・1分解に両面解釈があること。純両面や役あり、ロン可能を意味しない。本人が副露込み4枚持つ牌の5枚目は既存仕様どおり待ちから除く。
- S(d)は通常形・七対子・国士の最小形状シャンテン。副露/暗槓ありでは特殊形を除外し、通常形の固定面子数を反映。七対子は異なる7牌種の対子で、4枚を2対子にしない。Smin=min S(d)、Dm={d:S(d)=Smin}。形別Sstandard、Schiitoi、Skokushiも同じ牌種/面子規約に従う。
- S=0と既存W非空は形式聴牌の例外で一致しない場合がある。該当候補を含むS利用機会を`own_exhausted_shape_uncertain`として保留し、分母だけを都合よく変更しない。Tだけを用いる候補は従来W定義を維持する。この違いは実装前テストで照合する。
- 公開既知Kは本人保有全牌、全員の過去の河、公開副露、現在までのドラ表示の136ID和集合。鳴かれた牌を河と副露で二重計数しない。他家暗槓は公開された牌種4枚だけ。u(t)=4−K中の牌種t枚数。自分の候補打牌が手から河に移ってもKは減らない。他家未公開手牌・非公開ツモはKに入れない。
- U(d)は、打牌後手に未見牌種tを1枚仮想追加し、和了形又は次の最善合法形状打牌でSを減らせる牌種のu(t)合計。S=0では既存Wの未見待ち枚数合計。役・実山・和了確率を扱わない。自分の5枚目は追加しない。副露見送り13枚手のUも同じ一枚追加規約で評価する。
- Z(d)は二段の**受入改善余地**。各未見tを仮想追加し、その後の候補打牌でSを元のS(d)より悪化させずに達成できる最大Uを求め、max(0,最大U−U(d))をu(t)で重み付けして合計する。仮想tを既知へ移して未見枚数を1減らし、仮想打牌は公開牌として保持する。既に和了形が完成するtはZから除外し別カウンタへ。これは二手先の和了確率/期待値ではない。役・次の実他家行動は仮定せず、候補内の形状指標としてのみ利用する。
- V(d)は打牌後の本人純手牌＋固定副露の表ドラ枚数。現在までの表示だけを用い、赤・裏・将来カンドラは含めない。argmax_redは確認された赤ありルール下での赤物理牌保持枚数。赤のID規約が未確認なら保留する。

### 現物・スジ・手牌構成

- F1のGは対象リーチ者自身の過去の河牌種と一致する保有牌。Jは対象者の河に基づく完全スジ数牌。1/2/3は+3、7/8/9は−3、4/5/6は±3の両方を要し、字牌はJ外。Jを非現物に限りたい行は明示的にJ−Gとする。
- Gallは全成立リーチ者へのGの交差。D07の被覆人数はdが何人の成立者の河に存在するか。安全確率や人数加算した危険度ではない。Gnewは前回自己打牌直前に比べて現在の対象河に新たに加わった牌種の保有牌。
- B(d)=Σ（本人以外の3人p）打牌後純手牌中のp自身の河牌種に一致する**物理牌枚数**。Bは現時点の河現物資源の総量であり、将来リーチへの安全保証ではない。D01の判断前Bは同じ式をHに適用。D09は未リーチ他家だけを対象とし、Σp |打牌後保有牌種∩Rp|という被覆牌種・相手ペア数を用いる。これらの資源量は複数相手を合算するが、機会数は1打牌1のまま。
- 孤立牌は純手牌で同種1枚。数牌では同色±1/±2の牌種が純手牌にないことも要する。役牌は三元牌・現場風・自風。非役牌風牌はそれ以外の風牌。固定副露は切れる候補に含めない。
- 対子は純手牌同種ちょうど2枚。辺張種類は同色{1,2}/{8,9}、嵌張種類は同色{r,r+2}（r=1..7）の存在数。牌種セットを各1回数え、実際の面子分解を固定しない。重なり搭子数は距離1又は2の異なる牌種ペア2組が1牌種を共有する組合せ数。重複物理コピーで水増ししない。
- 三色骨格は同じ順子開始位置r（1..7）について3色ともr..r+2を2牌種以上保有。一通骨格は同色123、456、789各群で2牌種以上保有。保持/破壊は該当骨格の存在が候補前後で残る/消えること。完成役や本人の意図と呼ばない。
- argmin_offsuitは判断前の純手牌で最多の数牌色が一意の場合だけ、その主色以外の打牌後数牌枚数を最小にする集合。字牌は他色枚数に含めず別記。
- D13の壁条件は、候補数牌がロン完成牌となる全ての両面順子経路について、必要な相手側2牌種の少なくとも1つが本人の可視情報で4枚既知であること。単騎・嵌張・辺張・シャンポンの危険は消していない。牌種位置を端から列挙し、経験的な「壁なら安全」へ置き換えない。

### リーチ・役・点数

- RはFのうち、門前、必要持点、本人の次ツモ巡、対象GO/年代のルールを確認し、合法な宣言打牌候補集合Lが非空の機会。R0/R1は他家成立0/1人。行動は(d,宣言有無)。同じdを非宣言で切れることを確認する。step1で選択を測り、宣言牌放銃等でstep2不成立でも選択を消さない。ツモ和了を選んだ機会はF同様に母集団外。
- 「全合法宣言候補が…」は、判断前に列挙したL全体で条件を確認する。選んだ候補の待ちだけで良形/役あり条件を付けない。R09は現物/非現物の**宣言行動**を比較するが、ダマの実行はotherとして保存する。
- 固定役ロン形は、候補d後の仮想和了牌について、現在の門前・副露・場風・自風で確定する役がある形。裏・一発・海底/河底等の未来偶発役は含めない。構造だけの値と混ぜない。
- DR(d)は未見待ちのうち固定役ロン可能な牌があり、完全な自河/一時振聴を確認してその時点のダマロン経路が存在すること。未確認はfalseにせずunknown。一時振聴には過去の合法ロン見送り判定も必要なので、DR候補はBの高難度である。

- 点況はINITから判断時までに公表された持点・供託を反映する。未来のAGARI/RYUUKYOKUの精算を現在の点数へ戻さない。同点順位、予定最終局、連荘、飛び、延長、終了条件は年代・GOのルールが確認できる場合のみ利用する。S05/S08は現在の候補・待ち・相手についての仮想点移動であり、実際に誰から和了したかは使わない。
- 12000/8000/3900/1000点、残通常ツモ8、国士S<=3は事前の設計値。実測結果に合わせて閾値を増殖させない。持点100点単位と円滑に変換し、点単位を監査する。

### 副露応答

Oは他家提示牌直後、本人の自己成立リーチ前で、合法チー/ポン/必要なら槓と見送りが存在する場面。提示者の位置、手牌、喰い替え、山残数、ルールを確認する。鳴き方と合法直後打牌を列挙し、その応答で到達できる最良S/最大Uを定義する。実行は成立したNの形で判定し、実際の直後打牌が見込んだ最良形を選んだかも別に記録する。

本人Nが成立した応答と、競合がなく通常進行して見送りを観測できた応答をOの観測可能部分とする。他家N/ロン、切断、応答終了不明等は打ち切り。未成立の本人発声・操作を「見送り」と推測しない。打ち切りは判定器不明とは別statusで、分母外件数と率を併記する。競合による選択バイアスを除去できたとは主張しない。

Ocは本人の副露が実際に成立した提示牌に条件付け、その時点で複数種類/複数形の合法な鳴き方があった場合に形の選択を測る。M10〜12/M15は全提示牌に対する副露率ではない。見送り意図の推定が不要な代わりに、成立まで到達した局面だけの比較となる。

## 既存指標との差と候補数の管理

参照したのは現在の `tenhou.FEATURE_DEFINITIONS` 20項目、`choices.NAMES/DEFINITIONS/RULE` 3項目、新4項目のdefinitions/extractである。旧18＋交差5のカタログだけで重複判定していない。

- A1とP01：P01は非現物かつ形状テンパイになる実打牌を測る。A1では非現物ノーテンも分子。
- A4とP04：P04は形維持、A4は現物選択。第三選択があるため一般には補数でない。ただし情報の近さを明示し両方を独立発見としない。
- E3とD05：D05は最良SかつU同点の候補に限定。E3の単純な別名ではないが同じスジ判断系列。
- E4とD07：D07は共通現物がない場面で、守れる相手人数の違いを測る。
- 初回/対リーチ現物率とD03：現在切れる現物の重複/単独を比較し、現物を切れない機会を混ぜない。
- リーチ/副露の旧率は自己成立数や局数を分母とする場合がある。新候補は合法選択機会を必要とし、既存対局CSVだけで作れない。
- P01〜03、P08/09、P10/11、Q01/02、Q13〜15、R01/02、M06/07、M10/11は系列。P15〜20等の履歴条件、点況S群は親候補と交差する部分集合として検討する。

選択肢の存在が論理的に不可能な候補は採らない。例えば「全ての合法リーチ候補は非現物なのに、同じ手に通常の現物テンパイ候補がありそれだけ非宣言可能」とする定義は一般的な門前条件では矛盾し得るため採用せず、R09を現物/非現物の両方の合法宣言候補の比較にした。

候補一覧はCSV、個別の先行40候補と理由は `implementation_priority.md`、基盤の対応は `implementation_feasibility.md`、測定誤差と探索分離は `feature_quality_evaluation_plan.md` に記載する。今回、群内分散が小さい・差があると判明した新候補はない。
